# PersDataGate

Минимальный локальный шлюз: псевдонимизирует документ и промпт перед OpenAI и восстанавливает значения в ответе.

## Запуск

Нужны Docker Compose с поддержкой `gpus: all` и NVIDIA GPU, доступный из Linux-контейнеров. CPU fallback отсутствует.

```powershell
Copy-Item .env.example .env
# Заполните OPENAI_API_KEY и OPENAI_MODEL в .env локально.
docker compose up -d --build
```

Откройте http://localhost:8090. Модель загружается при первом запуске и кешируется в volume `model-cache`; первый запуск занимает больше времени. Без ключа и модели интерфейс доступен, но отправка в OpenAI заблокирована. После изменения `.env` выполните `docker compose up -d --force-recreate web`.

```powershell
docker compose ps
docker compose logs --tail 30 pseudonymizer
docker compose down
```

`down` сохраняет кеш модели. Не используйте `down -v`, если кеш нужно сохранить. Порт можно изменить через `WEB_PORT` в `.env`.

## Два сервиса

- `web`: FastAPI, статический интерфейс, диспетчеризация и OpenAI Responses API. Порт опубликован только на `127.0.0.1`. Документ и промпт объединяются с разделителями и обрабатываются одним вызовом.
- `pseudonymizer`: GLiNER `urchade/gliner_multi-v2.1` на CUDA, форматные правила и таблицы замен. Нет опубликованного порта и ключа OpenAI. Один процесс; GPU-инференс последовательный.

Одна кнопка выполняет `anonymize → OpenAI → deanonymize`. Справа видны параметры и полный текст запроса (`instructions` и `input`), исходный текст ответа и восстановленный текст. При сбое восстановления полученный ответ сохраняется в интерфейсе.

В OpenAI отправляется обработанный текст и фиксированная инструкция сохранять маркеры. Таблица соответствий и `mapping_id` не передаются. Используется `store=false`, без `temperature`, streaming и автоматических повторных отправок. `store=false` отключает хранение ответа для последующего извлечения API, но сам по себе не означает Zero Data Retention.

## Внутренний API

`POST http://pseudonymizer:8000/anonymize`

```json
{"text": "Иван Петров: ivan@example.org"}
```

Возвращает `mapping_id`, `text` с маркерами вида `⟦PERSON_<случайный-id>_1⟧` и `expires_at` в UTC.

`POST http://pseudonymizer:8000/deanonymize`

```json
{"mapping_id": "UUID из anonymize", "text": "Ответ с неизменёнными маркерами"}
```

Возвращает `text` и `warnings`. Восстановление выполняется одним проходом только для точных известных маркеров; неизвестные маркеры остаются без изменений. При неизвестной или истёкшей таблице — `404` с `detail: mapping_not_found`.

Таблицы живут в памяти **30 минут с момента создания**, повторное чтение не продлевает срок. Перезапуск pseudonymizer удаляет все таблицы. Для одной таблицы можно восстанавливать несколько ответов до истечения срока.

`GET /health/ready` у pseudonymizer проверяет загрузку модели; `GET /health` у web сообщает состояние конфигурации без значений ключа. Внешний API диспетчера: `POST /api/process` с `document` и `prompt`.

## Границы MVP

Только вставка текста, без файлов, OCR, истории и авторизации. Максимальный суммарный текст с разделителями — 50 000 символов. Тайм-аут внутренних HTTP-вызовов и OpenAI — 120 секунд каждый.

GLiNER ищет имена, адреса, даты рождения, номера документов и банковские идентификаторы. Правила дополняют email, телефоны, IBAN и номера документов по явному контексту. Общие даты, организации и географические названия вне адресов не входят в целевой набор. Длинный текст разбивается на перекрывающиеся фрагменты; повторные одинаковые значения получают один маркер. Разные написания и падежные формы автоматически не объединяются.

Распознавание может пропускать персональные данные или заменять лишнее. Это псевдонимизация, а не гарантия полной анонимности: контекст документа также может идентифицировать человека. Изменённые моделью маркеры автоматически не угадываются. Тексты и таблицы не записываются сервисом в файлы, логи или браузерное хранилище; содержимое страницы сохраняется только до её обновления.

## Тесты

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python -m pytest -q
```

Unit/API-тесты используют подменённые детектор и OpenAI и не требуют Torch, GPU, ключа или платных API-вызовов. CUDA, реальная модель и качество распознавания проверяются отдельно внутри Docker.
